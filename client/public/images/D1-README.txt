StyleHaven Online Clothing Store - Deliverable 1 (Client-side) - Updated Boutique Theme

Project type:
CMP7246 Web Application Development - D1 client-side website.

How to run:
1. Unzip the folder.
2. Open index.html in a browser.
3. Use the navigation menu to move between all pages.

Folder structure:
- css/style.css
- js/script.js
- images/ local raster images
- HTML pages in the root folder

Pages included:
1. index.html - Home
2. shop.html - Product listing with search, category filter and sorting
3. product.html - Product details, gallery, size selector, tabs and add-to-cart
4. collections.html - Clothing collections
5. cart.html - Shopping cart, quantity controls, delivery location and confirm order form
6. wishlist.html - Saved products using localStorage
7. blog.html - Fashion journal
8. about.html - About the brand
9. contact.html - Contact form and store details
10. login.html - Login form validation
11. signup.html - Registration form validation

Client-side features:
- Distinct boutique clothing-store visual style with coral, plum, blush, lavender and mint colours
- Responsive design for desktop, tablet and phone
- Mobile hamburger navigation
- Product search, category filter and price/rating sorting
- JavaScript product rendering
- Cart and wishlist using localStorage
- Cart quantity increase/decrease and remove item
- Checkout demo form with delivery location validation
- Contact, newsletter, login and signup form validation
- Product detail gallery, tabs, size selection and add-to-cart button
- Unique title and meta description on every page
- Semantic HTML sections, accessible labels, alt text and focus styles

Submission note:
This is D1 only. It does not use a server, database, Node.js, Express, React, MongoDB or real payment processing. Those server-side/database tasks belong to D2.
